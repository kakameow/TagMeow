# TagMeow

轻量的本地文件标签管理器：用「类型 → 标签」两级结构给文件与目录打标签，并围绕标签做筛选、索引与同步。

当前包含两个端：

| 端 | 实现 | 数据访问 | 局域网同步 |
| --- | --- | --- | --- |
| **Windows 桌面端** | C++ core + Qt Quick（Qt 6 / QML） | 绝对路径 | ✅ UDP 广播发现 + TCP 传输 |
| **Android 端** | 原生 Java（无 Kotlin），单 Activity | 「所有文件访问」+ 绝对路径 | ⛔ 未实现（界面占位） |

两端共用同一套数据模型与「**标签数据可重建**」的设计原则：索引库随时可以删掉重建，真正需要保护的只有标签库与文件上的标签。

## 功能简介

### 共同能力

- **目录管理**：添加 / 移除受管目录，自动扫描目录树并同步到本地数据库。
- **标签库**：类型 + 标签两级结构，每类一个颜色；支持添加 / 删除 / 改色，操作即时保存。
- **文件打标签**：文件与文件夹均可打标签，按行展示并实时编辑。
- **标签搜索**：包含 / 排除 / 只有 三种条件组合，实时计数（文件数 / 标签数）。
- **存储模式**：Sidecar（`.tag` 目录下的 JSON）与 Filename（标签写进文件名）二选一，可批量互转。
- **多语言**：扫描语言目录动态列出，支持导入语言文件。

### Windows 桌面端

- **文件定位**：双击文件行在系统资源管理器中打开所在目录并高亮；双击目录行直接打开。
- **局域网同步**：UDP 广播发现设备，TCP 传输；本机分享目录 / 从其他设备下载 / 下载记录。
- **主题**：支持浅色与深色主题界面。

*（此处可插入浅色 / 深色主题截图，建议命名为 `preview-light.png` 与 `preview-dark.png`。）*

### Android 端

- **单 Activity + 5 个标签页**：浏览 / 目录 / 标签 / 设置 / 同步（占位）。
- **应用内目录浏览器**：不依赖系统目录选择器，可在应用内新建文件夹并直接选为受管根目录。
- **缩略图**：图片 / 视频按需解码（`LruCache` + 采样缩放），其余按类型给图标。
- **打开文件**：数据库存绝对路径，交给系统应用时经 `FileProvider` 转 content Uri。
- **标签库导出 / 导入**：导出走系统「保存到…」，导入按「本类为空才整体替换」的规则合并。

## 项目说明与数据安全

TagMeow 是一个轻量的**本地文件标签管理器**，主要用途是通过标签对文件进行灵活分类。

本项目为个人练习作品，核心目标是管理文件的标签数据，整体设计遵循「**数据可重建**」的原则。日常查询和管理中，**不会修改原始文件数据，也不会改变原有的目录结构**（只读查询与管理）。

但以下两种情况会涉及真实文件的变动，请务必知悉：

| 模式 | 行为 |
| --- | --- |
| **Sidecar 模式** | 会在受管目录下创建 `.tag` 目录，用于存放标签 JSON 数据。 |
| **Filename 模式** | 会通过重命名文件的方式，将标签附加在文件名中（Android 端：只有文件可用，目录只能用 Sidecar）。 |

### ⚠️ 注意事项

1. **关于外部修改**：本程序的核心是管理标签数据，因此不会主动追踪外部对文件本身的修改（如手动移动、重命名、删除等）。请在使用过程中保持文件状态相对稳定。
2. **关于数据恢复**：**请务必注意不要删除标签数据！** 除此之外，其他所有数据（包括管理目录、标签表、数据库等）均可通过重新添加管理目录、重新扫描并填充数据库来恢复。

## 构建

### Windows 桌面端

- 需要 Qt 6.10+（MinGW）与 CMake + Ninja。
- 在 `windows/` 下配置并构建 `TagMeow` 目标。
- 运行目录需要 `language/`（界面语言文件）。

### Android 端

#### 环境要求

| 项 | 要求 |
| --- | --- |
| JDK | Gradle Daemon JVM 工具链 25（由 fooJay resolver 自动获取，无需手动装） |
| Android SDK | 需安装 `compileSdk 37` 平台 |
| Gradle | 由 Wrapper 提供 9.6.0，无需本机安装 |
| IDE（可选） | Android Studio 直接 Open 这个 `android/` 目录即可 |

## 文件说明

### Windows 桌面端发布包（TagMeow-win）

解压后运行 `TagMeow_.exe`。

- `TagMeow_.exe`：桌面端主程序。
- `tagmeow.exe`：命令行小工具。
- `config/`：配置文件；标签库、数据库、目录表等都在这里。
- `download/`：默认下载目录；局域网收到的文件默认保存在这里。
- `language/`：语言文件。

### Android 端

- `TagMeow.apk`：安装包。
